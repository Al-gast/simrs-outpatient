# SIMRS v1.0.4 — Dashboard dan administrasi

## Implementasi

Tren seluruh periode termasuk nol, donut count, total_amount/paid_amount tambahan pada kelompok status; BigInt, basis kas paid_at berbeda dari cohort tanggal visit. Enam rincian centered modal dengan filter, pagination dan retry. staff_name nullable melalui left join; edit/reset/status terpisah, role eksplisit dan PATCH versi lama. Audit Indonesia, searchable petugas termasuk nonaktif (50 hasil), filter action/entity eksak, reset, detail metadata. Entitas visits mencakup klinis/farmasi/lab/billing; tidak ada alias fiktif.
