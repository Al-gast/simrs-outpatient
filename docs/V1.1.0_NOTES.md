# SIMRS v1.1.0 — Rilis final dan verifikasi lokal

Baseline kumulatif v1.0.4, target upgrade v1.0.0. Tidak ada dependency, endpoint, schema atau migration baru pada fase terakhir; migration 000004 tetap dibutuhkan jika berasal dari v1.0.0.

## Perbaikan final

- REV-001/002: logout bearer lama tidak mencabut cookie akun lain; restore 401 tidak menghapus cookie baru. JWT invalid tetap tidak dapat digunakan.
- REV-003/004: marker generasi nonsecret untuk koordinasi tab, guard double submit login. Koordinasi best effort; profil browser berbeda untuk role simultan.
- REV-005: seed nomor RM menggunakan lebar minimal enam digit, tidak memotong sequence panjang; satu pemanggilan sequence. Seed tidak dijalankan ulang saat upgrade.
- REV-006: runner QA build sequential untuk MacBook 8 GB, port guard dan cleanup terisolasi tetap.
- REV-007/008: pemeriksaan route/sintaks Postman, fingerprint bisnis dan panduan migration-only.

Review mencakup autentikasi, RBAC, master/pendaftaran, versi klinis, stok, event lab, billing, reporting, akun, audit dan deployment lokal. Tidak membuktikan semua vulnerability tidak ada. BR-001 peringatan jam praktik dan BR-002 booking masa depan ditunda untuk mencegah regression; hari/jadwal aktif tetap diperiksa, kontrak hanya same-day WIB. Future booking membutuhkan validasi tanggal, queue/date dan pembatasan mulai pemeriksaan. Tidak ada fitur tersebut terselubung.

## Migration dan merge aktual

000001 schema/grants, 000002 reporting/index, 000003 ledger hardening telah diterapkan sebelum upgrade. 000004 menambah lima sequence tanpa perubahan baris bisnis; safeDown menolak bila telah digunakan. Pada MacBook konflik `ClinicalService.php` diselesaikan dengan mempertahankan `Yii\db\JsonExpression` untuk JSONB audit, vital dan diagnosis, sekaligus memasukkan aturan alasan terbaru. Source aktual berbeda dua bagian JSONB dari ZIP awal. Build dan pengujian berikutnya dilakukan pada hasil merge lokal tersebut.
